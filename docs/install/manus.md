# Install on Manus

Manus runs long agentic tasks, which suits this playbook well: it can do the intake, research your prospects, and produce the campaign document in one run. Two ways to install.

## Option 1: Knowledge (persistent, recommended)

Manus applies Knowledge entries across your tasks, so the playbook becomes a standing capability.

1. Download [`dist/cold-outreach-playbook-bundle.md`](../../dist/cold-outreach-playbook-bundle.md) from this repo.
2. In Manus, open **Settings → Knowledge** (on some versions: your avatar → Knowledge).
3. Create a new knowledge entry. Name it "Cold outreach playbook".
4. Paste the bundle's contents as the knowledge text. If the entry has a size limit, attach the file instead, or split it: Part 1 (the skill) as the knowledge text, and the rest as an attached reference.
5. In the trigger/when-to-use field (if offered), write: "Whenever I ask about cold outreach, cold email, prospecting, outbound sales, lead generation, or messaging strangers."
6. Start a task: "Build my cold outreach campaign. I sell [offer] to [audience]."

## Option 2: attach per task (no setup)

1. Download the bundle file.
2. Start a new Manus task and attach the file.
3. Prompt: "Follow the attached playbook exactly. Run its Phase 1 intake interview with me first, then deliver the complete campaign document it defines, saved as a file."

## Tip

Manus can browse. After the intake, ask it to also research 10 example prospects that match your ICP using the list-building rules in Part 3 of the bundle, so you leave with a starter list and not just the strategy.
